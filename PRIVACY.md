# Privacy Policy

Last updated: April 11, 2026

Astro.Expert Chart Parser processes data locally in the user's browser to parse Astro.Expert chart pages and dasha trees.

What the extension can access

- Page content on `https://*.astro.expert/*`
- Chart data shown on the page
- Birth details shown on the page, such as name, birth date and time, and birth place
- Dasha tree data shown on the page

How the data is used

- To parse visible Astro.Expert chart pages
- To display parsed results in the extension popup
- To let the user copy selected chart or dasha text
- To preserve the selected UI language locally in the browser

What the extension does not do

- It does not send parsed personal or chart data to any remote server
- It does not sell user data
- It does not use remote hosted code
- It does not use analytics, ads, or third-party trackers

Storage

- The extension stores only a small local preference for UI language using Chrome extension storage
- Parsed chart data is handled in memory for the current browser session

Contact

- Publisher contact details should be added in the Chrome Web Store listing before publication
